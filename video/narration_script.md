# Narration script (EN) — one line per scene, in recording order

Each line is read over its scene; record.cjs waits for each line's audio length.

1. (receipt) Receipts look like paper. In Korea, they don't go in the paper bin.
2. (title) This is Bunri. It tells you which bin something goes in, and shows the official sentence that says so.
3. (problem slide) Korea sorts household waste into more than a dozen streams, and the rules sit in a thirty-four page guide. Paper cartons alone: about sixty percent end up mixed into waste paper.
4. (pizza box) Type what you're throwing away. "Greasy" already answers the follow-up: oil-stained paper goes in the general bag.
5. (quote) Every answer quotes the source text, with the page and a link.
6. (no, clean) If it's clean, one tap changes the answer to paper.
7. (typo) A typo still works. When Bunri isn't sure, it offers three options instead of guessing.
8. (pet bottle) When the answer depends on something, it asks one question. Clear PET bottles are collected separately.
9. (umbrella) An umbrella you can't take apart goes in the general bag.
10. (soy milk carton) Rules change. The old guide said foil-lined cartons go in the trash; the 2026 guidance says paper cartons. Bunri shows the new rule and keeps the old one visible.
11. (hair dryer) If an item isn't in the official sources, Bunri says so. It doesn't invent a rule.
12. (Korean UI) Residents can use it in Korean, with the same data and sources.
13. (pilot log) A pilot log on the device counts lookups, unknown items, and "still not sure" taps.
14. (results) On a hundred and twenty-nine fresh test queries, Bunri resolved ninety-three percent, with two wrong-bin answers. A plain search box got twenty-four wrong.
15. (how) It runs offline in the browser. No server, no API key. Korean is split into letters, so spelling mistakes still match.
16. (pilot plan) To measure it: four weeks in one dorm or apartment block, counting non-recyclable items in the recycling bags before and after.
17. (end) Bunri. The code is on GitHub.
